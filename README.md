## Daily Study Structure

The regular study window is 8:00 AM–4:00 PM.

- 8:00–8:20 — Plan and review
- 8:20–10:00 — Learn the main topic
- 10:00–10:15 — Break
- 10:15–12:00 — Guided practice
- 12:00–12:45 — Lunch
- 12:45–2:45 — Interview-style problems and project work
- 2:45–3:15 — Verify results and correct mistakes
- 3:15–3:45 — Google Drive notes and screenshots
- 3:45–4:00 — GitHub upload or next-step planning

Every bootcamp day includes practice related to that day's topic.

Evening study is optional and is normally reserved for rest because of the part-time work schedule.

## Practice and Documentation Process

Each completed practice problem should include:

- A verified result
- A Google Drive note
- A screenshot
- A separate GitHub SQL or project file when applicable

Free practice resources include:

- StrataScratch free problems
- HackerRank problems
- W3Schools SQL practice
- Project-based analysis tasks

Only free and accessible StrataScratch problems are used. Problem titles, identifiers, results, screenshots, and access status are recorded only after verification.
